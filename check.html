Проверка сайта

Страница проверяет, что все файлы библиотеки лежат там, где нужно. Откройте её по адресу вашего GitHub Pages — она сама всё покажет.

Что делать, если есть красные строки
  1. Красная строка = файла нет по этому пути на сервере. Обычно причина одна: в репозиторий загрузились не все файлы (например, папки css, js, fonts, guides, pdf, icons остались внутри вложенной папки, а не в корне репозитория).
  2. GitHub не распаковывает архивы — zip нужно сначала распаковать у себя, а затем загрузить его содержимое.
  3. Проверьте: в корне репозитория должен лежать index.html, а рядом с ним — перечисленные папки. Уровень вложенности «репозиторий → папка → файлы» не нужен.
  4. После исправления подождите 1–2 минуты и обновите страницу с очисткой кэша (Ctrl+Shift+R / в меню браузера «Обновить без кэша»).
  5. Убедитесь, что открываете сайт по адресу Pages (имя-пользователя.github.io/имя-репозитория/), а не файл на сайте github.com.
