# Домашние гайды — библиотека инструкций по уходу

Статичный сайт-библиотека практических памяток: **«Стирка без ошибок»** и **«Уход за обувью»**.
Работает на GitHub Pages без сборки, баз данных и зависимостей — просто файлы.
Контент каждой страницы лежит **прямо в HTML**: сайт читается даже с выключенным
JavaScript, а скрипт добавляет поверх тёмную тему, меню, поиск и мелкие удобства.

## Что внутри

```
репозиторий (корень!)
├── index.html                     — главная: каталог гайдов (контент прямо в HTML)
├── check.html                     — страница-диагностика «все ли файлы на месте»
├── 404.html                       — возврат в библиотеку для несуществующих путей
├── .nojekyll                      — чтобы GitHub Pages отдавал файлы как есть
├── css/style.css                  — все стили: адаптив, печать, светлая и тёмная тема
├── js/
│   ├── app.js                     — тема, меню, поиск, чек-листы, прогресс чтения
│   └── registry.js                — РЕЕСТР ГАЙДОВ (меню); см. «Как добавить новый гайд»
├── guides/
│   ├── stirka-bez-oshibok.html    — «Стирка без ошибок» (контент внутри)
│   ├── uhod-za-obuvyu.html        — «Уход за обувью» (контент внутри)
│   └── _template.html             — шаблон нового гайда с комментариями
├── pdf/                           — PDF-версии для печати
├── fonts/                         — Inter + Playfair Display (локально, OFL)
├── icons/, favicon.svg, manifest.webmanifest
└── README.md
```

## Как опубликовать на GitHub Pages

**Важно:** GitHub не распаковывает архивы. Сначала распакуйте zip у себя,
загружать нужно **файлы**, а не сам архив. В корне репозитория должен лежать
`index.html`, а рядом — папки `css`, `js`, `guides`, `pdf`, `fonts`, `icons`.

### Способ 1 — через сайт GitHub (без git)

1. Создайте публичный репозиторий, например `care-guides`.
2. Распакуйте архив. Откройте репозиторий → *Add file → Upload files*.
3. Перетащите **содержимое** папки (все файлы и папки разом), дождитесь
   загрузки → *Commit changes*.
4. Проверьте: в корне репозитория видны `index.html` и папки. Если видите
   одну вложенную папку — зайдите в неё и переместите файлы на уровень выше
   (или загрузите заново, перетаскивая содержимое, а не саму папку).
5. *Settings → Pages* → Source: **Deploy from a branch**, Branch: **main**,
   папка **/ (root)** → *Save*.
6. Через 1–2 минуты откройте `https://<логин>.github.io/care-guides/`.

### Способ 2 — через git

```bash
git clone https://github.com/<логин>/care-guides.git
cd care-guides
# скопируйте сюда содержимое распакованной папки так, чтобы index.html был в корне
git add .
git commit -m "Библиотека гайдов"
git push
```

Затем включите Pages как в шагах 5–6 выше.

### Если что-то выглядит сломанным

Откройте `https://<логин>.github.io/care-guides/check.html` — страница
проверит каждый файл и покажет, чего не хватает на сервере. Красные строки
почти всегда означают «загружены не все файлы» или «файлы лежат во вложенной
папке». После исправления обновите страницу без кэша (Ctrl+Shift+R).

## Как добавить новый гайд

1. Скопируйте `guides/_template.html` в `guides/<имя-латиницей>.html`
   и заполните разделы — все места помечены `[квадратными скобками]`,
   готовые блоки (врезки, таблицы, шаги, чек-листы) перечислены в шапке шаблона.
2. Добавьте объект в список `GUIDES` в `js/registry.js` — гайд появится
   в меню на всех страницах.
3. На главной `index.html` скопируйте готовый блок `<article class="g-card">…</article>`,
   поменяйте текст и ссылку — гайд появится в каталоге. Заодно поправьте
   счётчики в блоке `hero-stats` выше (например, «3 гайда»).
4. Закоммитьте и запушьте — всё.

## Возможности

- Тёмная и светлая темы: кнопка в меню/шапке или клавиша **T**; выбор запоминается,
  по умолчанию — как в системе. Печать всегда идёт из светлой палитры.
- Поиск по гайдам (клавиша **/**), фильтрация карточек на главной.
- Прогресс чтения, активный раздел в содержании, продолжение с места остановки.
- Интерактивные чек-листы с сохранением отметок в браузере.
- Кнопки «Печать», «Поделиться», копирование ссылки на раздел (кнопка-скрепка).
- Всё адаптивно: телефон, планшет, компьютер; офлайн-печать PDF в комплекте.
